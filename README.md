# Programacion-libro-con-los-POO-correspondientes
Este programa cumple con la creacion de la clase Libro en donde muestra 5 libros con sus descripciones correspondientes.
Nombre: Carlos Diaz
Matricula: 2024-0733
Descripcion: El programa permite registrar la informacion de 5 libros, almacena de forma segura cada libro manteniendo sus atributos protegidos y accediendo a ellos mediante metodos publicos.
Datos de entrada: correponden a los datos ingresados manualmente.
Datos de proceso: Representa la logica de control y manejo de objetos que ejecuta el programa.
atos de salida: Es la respuesta estructurada que muestra al usuario en pantalla.
Importancia del POO: es importante porque permite modelar problemas del mundo real mediante objetos.
Como compilar y ejecutar el programa: Abrir el archivo dentro del programa presionar el verde donde dice depurar y se abrira el rpograma.
